# Ступень

Платформа, где работодатели публикуют реальные кейсы, стажировки и темы для курсовых и дипломных работ, а студенты берут их в работу, получают вознаграждение, собирают портфолио и находят работу.

**Демо-сайт:** https://bell-igor.github.io/practice/ · **Репозиторий:** https://github.com/Bell-igor/practice

> **Статус:** рабочий прототип (front-end). Данные хранятся в браузере пользователя, реальные платежи и модерация не подключены.

## Идея

Между вузом и первой работой есть разрыв: студенту нечего показать, а компании нужны руки на задачи, до которых не доходят руки у штатных сотрудников. Ступень закрывает этот разрыв:

- **студент** получает реальный кейс, наставника, оплату за результат и строчку в резюме;
- **компания** закрывает задачу и присматривает кандидата в деле;
- **вуз** получает актуальные темы работ и связь с индустрией.

## Возможности

### Для студентов

- Каталог из 16 демо-кейсов: стажировки, практика, разовые проекты, темы курсовых и дипломов.
- Поиск и фильтры по типу, направлению, формату работы и наличию оплаты, сортировка по дедлайну и вознаграждению.
- Карточка кейса: описание, задачи, требования, что получит студент, наставник, дедлайн, число мест.
- Отклик с сопроводительным сообщением и отслеживание статуса (отправлен → на рассмотрении → принят / отказ).
- Избранное.
- Портфолио: добавление работ со ссылками и описанием результата.
- Профиль: вуз, специальность, курс, навыки, контакты, ссылка на резюме.

### Для работодателей

- Кабинет со статистикой: кейсы, отклики, принятые исполнители, просмотры.
- Публикация и редактирование кейсов: тип, направление, формат, сроки, требования, задачи, вознаграждение.
- Работа с откликами: профиль кандидата, портфолио, приём / рассмотрение / отказ.
- Профиль компании: отрасль, город, размер, сайт, описание.
- Публичная страница компании со всеми её кейсами.

### Общее

- Регистрация и вход с выбором роли, демо-аккаунты в один клик.
- Светлая и тёмная темы в сине-графитовой палитре, выбор запоминается.
- Адаптивная вёрстка: от 360 px до широких экранов.
- Демо-состояние можно сбросить в личном кабинете.

## Стек

- **React 19** + **TypeScript**
- **Vite 6**
- **React Router 7** (HashRouter — маршруты работают на любом статическом хостинге)
- **lucide-react** — иконки
- CSS-переменные, собственный дизайн-система, без UI-библиотек
- Хранение: `localStorage` (демо-режим)

## Запуск локально

```bash
pnpm install
pnpm dev       # http://localhost:5173
pnpm build     # production-сборка в dist/
pnpm preview   # предпросмотр собранной версии
pnpm typecheck # проверка типов
```

Если pnpm не установлен: `corepack enable` или `npm i -g pnpm@11`.

## Публикация на GitHub Pages

Сайт уже опубликован: https://bell-igor.github.io/practice/

Репозиторий содержит workflow `.github/workflows/deploy.yml`, а GitHub Pages включён с источником **GitHub Actions**. Каждый пуш в `main` пересобирает и публикует сайт автоматически (1–2 минуты).

Если разворачиваете форк:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите workflow на вкладке **Actions** или сделайте пуш в `main`.

Сборка использует `base: './'` и хеш-маршрутизацию, поэтому работает и в подпапке, и при открытии `dist/index.html` напрямую с диска.

## Ограничения прототипа

- Нет сервера и общей базы: каждый браузер хранит своё состояние, изменения не видны другим пользователям.
- Нет реальной оплаты, договоров и модерации — условия кейсов фиксируются только текстом.
- Загрузка файлов (резюме, портфолио) не реализована: используются ссылки.
- Для полноценной версии нужны backend (API + БД), аутентификация, модерация и эскроу-платежи.
